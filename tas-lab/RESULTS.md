# 2026-09-06 DeepSeek TaS 实测

**完整 API 流程已跑通；本轮没有观察到准确率增益，不能据此证明 TaS 提升编程能力。**

使用 Kimi Code 现有官方 DeepSeek 配置，模型为 `deepseek-v4-pro`，
Chat Completions，显式开启 `max` 思考。未改动 Kimi 配置或 Pi 源码。
模型只接收本地生成的图题；标准答案由独立图算法校验。

## 两轮实验分开解释

第一轮原计划四个较长图题，但第一个约 70,523 输入 token 的样本，两个首遍均达到
16,384 输出 token 上限，所有输出都用于推理，没有最终答案。评测随即停止，
未运行 append/state。这是输出预算不足的证据，不是 TaS 得零分或无效的证据。

第二轮是独立的容量校准：重新固定两个较小样本，使用新的种子，将所有条件的
输出上限统一设为 32,768 token，仍保持 max 思考。它同时改变了任务和预算，
不能与第一轮进行单变量比较，也不是论文原始基准复现。

| 校准样本 | 首遍输入 token | 首遍 1 | 首遍 2 | Append | State |
| --- | --- | --- | --- | --- | --- |
| 入边检索，24k 字符 | 14,251 | 全对 | 全对 | 全对 | 全对 |
| 最短距离检索，60k 字符 | 35,424 | 全对 | 全对 | 全对 | 全对 |

两题的 EM 和集合 F1 在所有条件下均为 1。首遍已经达到满分，反馈条件没有
展示准确率改进空间；两个样本也不足以估计稳定收益。

两次首遍使用相同 x/q；append/state 使用同一份 T、相同 x/q，q 始终末尾。
T 每条截断到 50,000 **字符**。本轮没有实现目标扩展的 50,000 **token** 上限。

## 成本与耗时发现

| 样本 | Append 最终一遍 | State 最终一遍 | Append 输出 token | State 输出 token |
| --- | --- | --- | --- | --- |
| 入边检索 | 6.30 秒 | 22.02 秒 | 421 | 1,423 |
| 最短距离检索 | 20.13 秒 | 42.00 秒 | 1,408 | 2,838 |

本轮 state 最终一遍更慢、生成更多 token，且未命中缓存；append 两次共命中
38,784 输入 token。该现象可能受题型、缓存与服务端波动影响，不能推广为排序规律。
上表未包含首遍生成成本：入边样本两次首遍用了 21,418 / 30,012 推理 token，
这是整个流程的主要成本来源之一。

校准批次实际共享首遍，总费用低峰估算 $0.321777。若分别部署一项策略，
两题合计 append 约 $0.240609，state 约 $0.270168，均包括两次首遍加自身最终一遍。
两策略独立部署账不能相加当作本次实验实际支出，因为本次共用了首遍。

包含冒烟、被截断的长图首遍及校准批次，本次总共 **11 次 API 请求**：

- 输入 460,949 token，其中缓存命中 38,784。
- 输出 101,349 token，其中推理 100,450；推理已包含在输出里，不重复计费。
- 所有请求都返回 usage；按当天低峰费率估算共 **$0.480153**，约 **$0.48**。
- 同用量按高峰费率估算为 $0.960306；上述金额均是 usage 推算，不是账单回执。

费率取自 [DeepSeek 官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)，
2026-09-06 为周日，属于该页定义的低峰时段。

## 工程验证与下一步

14 项离线测试通过，覆盖图标准答案、确定性生成、严格判分、输入顺序、流式分帧、
凭据错误脱敏和费用计数。另对已保存的真实请求逐字重建并验证 prompt/hash、
共享轨迹和分数：长图批次 2 次、校准批次 8 次全部通过。

评测器与修订后的方案可以继续使用。下一轮应使用独立校准集确定难度和输出预算，
避免满分或普遍截断，再冻结尚未观察模型结果的测试集，扩大配对重复数并补上
相近实际成本的直接多采样对照。现在还不能根据这些结果决定默认开启 TaS
或进入带写入工具的并发首试。

以上记录描述独立 API 实验。后续 [Pi 扩展](../tas-extension/README.md) 已完成
会话取消、切换、压缩等离线生命周期测试及真实 DeepSeek 工具循环验收；这些工程验证
不改变本批图题的结果。带写入工具的隔离首试和真实编程任务效果仍未验收。
