# ds-maxpower v0.1.0

首个 Pi TaS 插件版本：通过 `/tas on` 开启，每个新任务独立推理两次，再把轨迹放到原上下文前进入正常工具循环。`/tas off` 关闭，`/tas status` 查看，Esc 取消。

## 安装

需要已配置 DeepSeek V4 的 Pi；本版已验证 Pi 0.85.1。

下载 `ds-maxpower-0.1.0.tgz`，校验后解压，在 Pi 中安装解包目录：

```sh
shasum -a 256 -c SHA256SUMS
tar -xzf ds-maxpower-0.1.0.tgz
pi install ./package
```

校验文件列出 tgz 和 zip；完整校验需下载两个包。也可只将已下载文件的校验行交给校验工具。
ZIP 内容相同，解压后安装 `ds-maxpower-0.1.0` 目录。请保留安装目录，Pi 直接引用其文件。
核心插件使用 Pi 的模型认证，不依赖 Kimi Code。仓库源码另提供可选 Kimi 启动器与开发环境准备脚本。

## 验证与边界

- 27 项扩展测试、14 项 API 实验测试通过；类型检查通过。
- Release 解包后，真实 Pi loader/SDK 的 12 项集成测试通过。
- DeepSeek 实测：2 次首遍、1 次 read、1 次最终回答，共 4 次 HTTP 请求。
- 默认关闭；首遍无工具；工具续轮复用轨迹；文件快照、取消、压缩与用量归档均有覆盖。
- 每条轨迹最多 50,000 Unicode 字符，尚未实现精确 token 裁剪。
- 当前是实验性首版，已有小样本实验未证明准确率或编程能力提升。

附件不包含凭据、本机会话、原始推理记录、Pi 源码或 node_modules。
